# 業務報帳通

發票／收據拍照報帳 App（手機網頁，可「加入主畫面」當 App 使用）。

## 功能

- **拍照報帳**：拍電子發票證明聯，自動辨識 QR Code，帶入發票號碼、日期、買賣方統編、金額與品名。也可拖曳或貼上截圖。
- **送出前自動檢核**：統編檢查碼、買方統編是否為本公司、發票號碼格式與重複報帳、5% 稅額、報帳期限、不得扣抵科目（營業稅法§19）。
- **七種憑證**：電子發票、三聯式、三聯式收銀機、交通票證、二聯式／未打統編、收據、支出證明單。
- **線上簽核**：業務送出 → 主管核准／退回 → 會計入帳，每一步留下軌跡。
- **會計彙整**：依營業稅期別（兩個月一期）彙整進項明細與可扣抵稅額，匯出 CSV（Excel 可開）、列印費用報銷單與憑證黏貼頁。
- **離線可用**：資料存在裝置的瀏覽器中，可下載完整備份。

## 使用方式

1. 把 `app/` 資料夾放到任何 **HTTPS** 靜態網站（例如 GitHub Pages、公司內部網站）。相機即時掃描需要 HTTPS。
2. 手機用瀏覽器開啟，選「加入主畫面」。
3. 首次開啟有範例資料，到「設定」填入公司名稱、統編與姓名，再到「總覽」清除範例。

## 目前限制（第一階段）

- 資料只存在各自的裝置，重複發票檢查也只在同一台裝置內有效。全公司共用需加上後端伺服器（見 `docs/報帳電子化規劃.md` 第 4 節）。
- 右上角「業務／主管／會計」切換是為了示範流程，正式版應改為公司帳號登入與權限控管。
- 紙本三聯式發票與收據目前需手動輸入欄位（照片仍會保存）。
